=== Approach Description ===
1. For each test subject, created separate features per subject to avoid leakage
2. Trained a separate Bayesian Ridge model on each training subject's data
3. For each test sample, computed similarity to each training subject's feature space
4. Weighted predictions by similarity and reliability (inverse uncertainty)
5. Made final prediction as uncertainty-weighted combination of subject-level predictions
6. This reduces inter-subject variability by adapting to subject-specific characteristics
   while leveraging population knowledge through uncertainty-guided weighting
